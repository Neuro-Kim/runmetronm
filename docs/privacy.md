# Pulse Run 개인정보처리방침

**최종 업데이트:** 2026년 5월 12일

본 방침은 Pulse Run 및 Pulse Run Remote(이하 "본 앱")가 사용자의 개인정보를 어떻게 처리하는지 설명합니다.

## 1. 수집하는 정보

본 앱은 **어떠한 개인 식별 정보도 수집·전송·저장하지 않습니다.** 광고 식별자, 위치, 연락처, 사용 분석, 충돌 로그 등 외부로 전송되는 데이터가 없습니다.

본 앱은 인터넷 권한을 선언하지 않으며, 외부 서버와 통신하지 않습니다.

## 2. 단말기 내부에 저장되는 정보

다음 항목은 사용자의 기기 내부 저장소에만 보관되며 외부로 전송되지 않습니다.

- BPM, 클릭 음량, 박자 수, 톤 프로파일 등 메트로놈 설정값

해당 데이터는 앱을 삭제하면 함께 제거됩니다.

## 3. 폰–시계 간 통신

본 앱은 Wear OS 동반 앱(Pulse Run Remote)과 BPM 조정, 재생/정지, 음량 변경 등의 명령을 Google Play Services Wearable API를 통해 주고받습니다. 이 통신은 페어링된 두 단말기 간에서만 이뤄지며 외부 서버를 거치지 않습니다.

## 4. 요청 권한과 사용 목적

| 권한 | 사용 목적 |
| --- | --- |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 화면을 꺼도 메트로놈이 끊기지 않도록 전경 서비스로 재생 |
| `POST_NOTIFICATIONS` | 전경 서비스 상태 알림 표시 |
| `WAKE_LOCK` | 재생 중 절전 모드 진입을 방지 |

## 5. 백업

Android의 표준 자동 백업(Auto Backup)이 활성화된 기기에서는 OS가 앱 설정값을 사용자의 Google 계정에 암호화하여 백업할 수 있습니다. 이 백업은 Google이 관리하며 본 앱 개발자는 접근할 수 없습니다. 사용자는 기기 설정에서 자동 백업을 끌 수 있습니다.

## 6. 제3자 서비스

본 앱은 Google Play Services Wearable API(폰–시계 통신용)만 사용하며, 외부 분석·광고·크래시 리포트 SDK를 일절 포함하지 않습니다.

## 7. 아동 정보

본 앱은 만 13세 미만 아동을 대상으로 하지 않으며, 해당 연령대로부터 의도적으로 어떠한 정보도 수집하지 않습니다.
